

# 🧮 Simple Calculator - Python

A simple calculator that performs 4 basic operations.

## Features
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- Shows error message when dividing by zero

## How to Run

python calculator.py

## Requirements
- Python 3.x
